# Online-Retail-Customer-and-Sales-Analysis
Analyzed online retail transaction data to identify customer, product, revenue and country-level sales patterns.
Cleaned transaction data using Python and Pandas, including missing values, duplicates and cancelled transactions.
Performed EDA using Pandas and visualization libraries to identify key sales and customer patterns.
Built an interactive Power BI dashboard covering revenue, customers, products and country-level insights.
Presented business findings to support customer, product and sales decision-making.
